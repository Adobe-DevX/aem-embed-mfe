AEM Fragment Embed (Custom Element + Shadow DOM)

This page loads <fragment-embed>, a custom element defined in /scripts/fragment-embed.js, built following the aem-embed pattern (custom element + Shadow DOM, driven by a single url attribute). It fetches the fragment's .plain.html inside a Shadow DOM and loads the matching block's CSS/JS (/blocks/hero-lab/hero-lab.js and .css).

Note: this uses a lightweight loader instead of the stock aem-embed.js. The source project's own scripts.js bootstraps AEM Commerce config and assumes it owns the page, which throws when run inside a foreign host — see the README for details.

Note: the source project (main--vwr--ynaka-adobe.aem.page) does not currently send an access-control-allow-origin header, so the fetch below will fail with a CORS error in the browser console unless you've enabled it (e.g. via a CORS-unblocking extension, or on the source project itself). See the README for the real fix.
